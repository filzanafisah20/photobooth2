# JUMINO - Makeup Tutorial Website

Website tutorial makeup kelompok Jumino. Dibuat dengan HTML, CSS, JavaScript,
dan tutorial step-by-step versi Python yang di-embed dari Trinket.

## Halaman
- **Home** - perkenalan tim & presentasi
- **Design Process** - proses pembuatan + Canva
- **Produk** - tutorial makeup interaktif (Trinket Python)

## Cara hosting di GitHub Pages
1. Upload semua isi folder ini ke repo GitHub.
2. Settings > Pages > Source: branch `main`, folder `/ (root)` > Save.
3. Website live di `https://<username>.github.io/<nama-repo>/`

## File
- `index.html`, `style.css`, `script.js` - website utama
- `images/` - logo & gambar
- `main.py` + `trinket_gif/` - kode & gambar untuk Trinket (opsional, bukan bagian website)
